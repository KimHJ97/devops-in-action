# 1. 셸 스크립트 기초

## 1-1. 셸 스크립트란

최초의 셸은 벨 연구소에서 스티븐 본이 갭라한 본셸이며, 이를 개선한 본 어게인 셸, 콘셸, Z셸 등이 만들어졌다. 1989년 브라이언 폭스가 GNU 프로젝트를 편리하게 사용하기 위해 사용자 친화적으로 만든 것이 바로 bash(Bourne again shell)이다. bash는 본셸을 기반으로 만들어졌으며, 자유 소프트웨어 재단의 주요 리눅스 시스템의 기본 셸로 쓰인다. 따라서 bash 셸은 GNU 운영체제, 리눅스, 맥OS X 등 다양한 운영체제에서 사용 중이며 현재 린구스의 표준 셸이다.

 - sh
    - 개발자: 스티븐 본
    - 설치 위치: /bin/sh
    - 설명: 1979년에 개발되었으며, 많은 셸 스크립트의 기반이 되는 셸
 - bash
    - 개발자: 브레인 폭스
    - 설치 위치: /bin/bash
    - 설명: 리눅스에서 가장 많이 사용되는 셸로 본셸을 토대로 C셸과 Korn셸의 기능들을 통합시켜 개발되었음
 - ksh
    - 개발자: 데이비드 콘
    - 설치 위치: /bin/ksh
    - 설명: 1980년대 벨 연구소에서 개발했으며, C 셸의 많은 기능을 추가하여 개발.
 - csh
    - 개발자: 빌 조이
    - 설치 위치: /bin/csh
    - 설명: 1978년 버클리 대학에서 개발되었으며 C와 비슷한 스타일로, 스크립트 작성 가능
 - tcsh
    - 개발자: 켄 그리어
    - 설치 위치: /bin/tcsh
    - 설명: csh에 커맨드 히스토리 등의 추가 기능을 보완
 - zsh
    - 개발자: 폴 팔스타드
    - 설치 위치: /bin/zsh
    - 설명: 1990년에 개발되었으며 bash, ksh 및 tcsh의 일부 기능을 비롯하여 여러 가지가 개선된 확장된 본셸

## 1-2. 셸 스크립트 기초 문법

### 2-1. 셸 스크립트 만들기

셸 스크립트 파일을 만들 때는 일반적으로 sh 확장자를 사용한다. 셸 스크립트를 만들 떄는 시작시 `#!/bin/bash`를 붙여 해당 파일이 셸 스크립트라는 것을 알려준다.

```sh
# 1. 셸 스크립트 작성
$ vi myshell.sh

#!/bin/bash
echo "hello world"


# 2. 셸 스크립트 실행
$ sh myshell.sh


# 3. 셸 스크립트 파일에 실행 권한을 주고, 직접 셸 스크립트 실행
$ chmod +x myshell.sh
$ ./myshell.sh
```
