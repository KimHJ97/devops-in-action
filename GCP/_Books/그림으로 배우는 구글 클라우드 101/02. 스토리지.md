# 스토리지

## 1. 저장소 유형

| 분류                             | 주요 서비스                                      | 특징               | 대표 사용 사례          |
| ------------------------------ | ------------------------------------------- | ---------------- | ----------------- |
| 🧱 __객체 스토리지(Object Storage)__ | __Cloud Storage__                           | 파일(객체) 단위로 저장    | 이미지, 로그, 백업, 정적 웹 |
| 💽 __블록 스토리지(Block Storage)__  | __Persistent Disk__, __Local SSD__          | VM에 연결되는 디스크     | VM OS, DB 디스크     |
| 📂 __파일 스토리지(File Storage)__   | __Filestore__, __Storage Transfer__         | 파일 공유용 네트워크 스토리지 | NFS 서버, ML 학습 데이터 |
| 🗄️ __데이터베이스/하이브리드 스토리지__      | __Cloud SQL, Spanner, Bigtable, Firestore__ | 구조화된 데이터 저장      | 트랜잭션, 실시간 분석      |

### 1-1. Cloud Storage (객체 스토리지)

객체 스토리지는 바이너리, 객체 데이터, 미디어, 문서, 로그, 백업, 애플리케이션 바이너리, VM 이미지와 같은 비정형 데이터에 사용된다. 구조적으로 평평한 데이터 환경에 저장된 개별 데이터 단위인 객체는 ID, 메타데이터, 속성, 실제 데이터로 구성돼 있다.

 - 파일을 객체 단위로 저장하고, URL로 접근 가능한 전역 스토리지
 - AWS의 S3와 동일한 서비스
 - 파일을 “버킷(Bucket)” 단위로 관리
 - 각 객체(Object)는 메타데이터 + 데이터로 구성
 - 전 세계 어디서나 접근 가능 (Public/Private 설정 가능)

<br/>

### 1-2. Persistent Disk (블록 스토리지)

블록 스토리지에서 파일은 자체 고유 주소를 갖는 동일한 크기의 데이터 블록으로 분할되지만, 파일 스토리지에서 사용하는 파일 구조 또는 객체 스토리지에서 사용하는 메타데이터와 같은 정보는 가지고 있지 않다. 모든 파일에 접근하기 위해 서버의 운영체제는 고유 주소를 사용하여 블록을 파일로 만드는데, 이 방법은 파일에 접근하기 위해 파일 계층구조와 디렉토리를 탐색하는 것보다 시간이 덜 걸린다.

블록 스토리지는 단일 경로의 데이터에 의존하지 않기 떄문에 데이터를 빠르게 추출할 수 있다.

 - Compute Engine VM에 연결되는 가상 디스크
 - VM 종료 시에도 데이터 유지
 - 스냅샷(Snapshot) 기능으로 백업 가능
 - 읽기 전용 다중 연결(Read Replica) 지원
 - 영역(Zone) 내에서만 연결 가능

<br/>

### 1-3. Local SSD

 - VM에 물리적으로 직접 연결된 초고속 로컬 디스크
 - 속도: 매우 빠름 (최대 2.4TB, 지연 수 μs 단위)
 - 지속성: VM 종료 시 데이터 삭제됨 (휘발성)
 - 용도: 캐시, 임시 데이터, 대규모 연산 중간 결과
 - 주의점: 내구성 없음 — 지속 데이터 저장용으로 부적합

<br/>

### 1-4. Filestore (파일 스토리지)

공유 파일 시스템인 파일 스토리지는 데이터가 폴더 안에 단일 조각으로 저장된다. 파일 스토리지에서 데이터는 파일 형태로 저장되고, 파일은 폴더로 구성되며, 폴더는 디렉토리와 하부 디렉토리 계층구조 아래에 존재한다. 데이터에 접근할 떄 컴퓨터가 이 데이터를 찾기 위해서는 경로를 알고 있어야 한다.

 - NFS(Network File System) 기반 파일 공유 스토리지
 - 고성능 파일 접근이 필요한 워크로드에 적합
 - GKE + Filestore 조합으로 AI/ML 훈련 데이터셋 관리
 - 파일 단위 잠금, 디렉토리 구조 지원
