# 인터넷 안되는 현상

인터넷이 끊기는 현상은 모뎀, 공유기, 랜선, PC 설정 문제 등 다양한 원인으로 발생할 수 있습니다.

 - `장비 재부팅 및 점검`
    - __모뎀 및 공유기 재부팅__: 모뎀과 공유기의 전원을 분리하고 10~10초 정도 기다린 후 다시 연결합니다.
    - __모뎀 상태 확인__: 모뎀 앞면의 LED가 빨간색이나 주황색으로 켜져 있다면, 단선이나 기기 분량일 수 있으니 통신사 고객센터에 문의합니다.
    - __공유기 초기화__: 공유기 뒷면에 있는 'Reset' 구멍을 핀셋 등으로 약 5~10초간 꾹 눌러 초기화합니다.
    - __랜선 점검__: 모뎀과 공유기, 컴퓨터에 연결된 랜선이 제대로 꽂혀 있는지 확인하고, 헐겁다면 다시 꽂아줍니다. 
 - `PC 설정 확인`
    - 네트워크 어댑터 설정: 윈도우 설정 > 네트워크 및 인터넷 > 고급 네트워크 설정 > 어댑터 옵션 변경으로 이동합니다. 사용 중인 이더넷 연결을 마우스 오른쪽 버튼으로 클릭하고 사용 안 함으로 변경했다가 사용으로 다시 변경합니다.
    - 네트워크 재설정: 윈도우 설정 > 네트워크 및 인터넷 > 고급 네트워크 설정 > 네트워크 초기화를 실행합니다. 이 기능은 PC를 다시 시작하며 네트워크 설정을 초기화합니다.
    - 무선 어댑터 설정: 무선 연결을 사용한다면, 전원 관리 옵션에서 무선 어댑터가 자동으로 꺼지지 않도록 설정되어 있는지 확인합니다.

## 1. 문제 파악하기

 - 다른 장비에서 되는지 확인 → PC 문제인지 공유기 문제인지 분리
 - WiFi가 문제인지, 유선도 문제인지 구분
 - 공유기 LED 확인(WAN/LAN/DNS 상태)
 - ipconfig /all, ping 8.8.8.8, ping google.com
 - 인터넷만 안 되고 DNS만 깨진 경우 구분
    - 공유기 설정 페이지(192.168.x.x) 접속 확인
    - 내부망 서버/프린터 접속 확인
    - 공유기(WAN) IP 할당 상태 확인
        - WAN IP가 0.0.0.0 / 할당 안됨 → ISP 장애 또는 케이블 문제
        - 공유기 WAN에 공인 IP가 있음 → 내부는 정상
 - 공유기/모뎀 재부팅
 - 그럼에도 해결 안 되면 → ISP 장애 여부 확인
 - 사무실/집이면 → 통신실 스위치 상태 체크

<br/>

## 2. 문제 사항

 - 장비 문제
 - 소프트웨어 문제
 - 네트워크 환경/통신사 문제

### 2-1. 장비 문제

 - `모뎀/공유기 문제`
    - 전원 어댑터 불량 또는 헐거짐
    - 장비 과열로 인한 인터넷 연결 불안정
    - WAN 포트/케이블 느슨함
    - 공유기 DHCP 기능 오작동
    - 포트 고장 (특정 LAN 포트만 안 됨)
 - `인터넷 케이블 문제`
    - UTP 케이블 단선/단락
    - 벽면 포트 불량
    - 광케이블(ONU) 단선 또는 노후화
    - 랜선 카테고리 문제(CAT5 이하 등)

<br/>

### 2-2. 소프트웨어 문제

 - `네트워크 설정 문제`
    - IP 충돌
    - 고정 IP 잘못 설정
    - Gateway/DNS 설정 오류
    - 방화벽(Firewall)에서 인터넷 차단
    - 프록시 설정 걸려 있음
    - VPN 연결이 인터넷 트래픽을 막고 있음
    - 브라우저 또는 OS의 DNS 캐시 충돌

 - `드라이버 / OS 문제`
    - 네트워크 드라이버 손상 또는 오래된 버전
    - Windows 네트워크 서비스 비정상 (DHCP Client, DNS Client 등)
    - macOS 네트워크 location 설정 오류
    - 네트워크 stack 오류 (Winsock 등)
 - `네트워크 드라이버 해결 방법`
    - __네트워크 어댑터 껐다 켜기__
        - Win + R → ncpa.cpl
        - 해당 이더넷/WiFi 어댑터 우클릭 → 사용 안 함
        - 다시 우클릭 → 사용
    - __장치 관리자에서 드라이버 재로드(Windows)__
        - Win + X → 장치 관리자
        - 네트워크 어댑터 선택
        - 해당 장비 우클릭 → 장치 제거(언인스톨)
        - 재부팅 → 자동으로 다시 설치됨
    - __드라이버 업데이트(재설치 포함)__
        - Windows 자체 업데이트
            - 장치 관리자 → 우클릭 → 드라이버 업데이트
            - 보통 최신 버전까지는 안 찾아주지만, 간단한 오류는 해결됨.
        - 제조사 드라이버 설치 (가장 확실함)
            - 사용 중인 PC/노트북/메인보드 제조사에서 직접 다운로드
            - Intel LAN/Wi-Fi → Intel Driver & Support Assistant
            - Realtek LAN → Realtek 공식 사이트
            - Killer WiFi(게이밍 노트북) → Killer Control Center
            - Dell/Lenovo/HP → 장치 서비스 페이지에서 모델명 검색

<br/>

### 2-3. 네트워크 환경/통신사 문제

 - `ISP(인터넷 제공업체) 장애`
    - KT/LG/SKT 회선 장애
    - 건물 전체 광케이블 문제
    - 인터넷 단자함(통신실)의 H/W 문제

 - `외부 네트워크 품질 문제`
    - 특정 사이트만 접속 안 됨 (해당 서버 문제)
    - 지역 라우팅 문제 (DNS는 됨, TCP 연결만 안됨)
    - 해외망 제한 또는 지연
    - 특정 포트 차단된 회선 (예: 22, 8080 등)
 - `건물 내부 네트워크 문제`
    - 빌딩 스위치 장애
    - Office VLAN 문제
    - PoE 스위치 전원/포트 다운
    - 네트워크 루프 발생 (스위치 전체 다운)
