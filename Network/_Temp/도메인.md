# 도메인

## 1. DNS

DNS는 도메인 네임 시스템(Domain Name System)의 약자로, 사람이 읽기 쉬운 웹사이트 주소(예: www.naver.com)를 컴퓨터가 이해하는 숫자로 된 IP 주소(예: 125.209.222.141)로 변환해주는 인터넷 시스템입니다.

 - __DNS 주요 역할__
    - `도메인 이름을 IP 주소로 변환`: 사용자가 입력한 www.example.com과 같은 도메인 이름을 192.0.2.44와 같은 IP 주소로 변환하여 웹사이트에 접속할 수 있게 합니다.
    - `기억하기 쉬운 주소 제공`: 사람이 복잡한 숫자로 된 IP 주소를 일일이 외울 필요 없이, www.google.com과 같은 익숙한 도메인 이름을 사용하여 인터넷을 편리하게 이용할 수 있도록 돕습니다.
    - `인터넷 주소록 역할`: 인터넷상의 모든 웹사이트와 서버의 IP 주소 정보를 저장하고 관리하는 일종의 '인터넷 전화번호부' 역할을 합니다.
    - `계층 구조 구성`: 인터넷을 최상위 도메인(TLD)과 하위 도메인으로 나누어 관리하는 계층 구조를 만듭니다. 
 - __DNS 동작 방식__
    - 사용자가 브라우저에 도메인 이름을 입력합니다.
    - DNS 서버가 이 요청을 받아, 해당 도메인 이름에 대한 IP 주소를 찾기 시작합니다.
    - DNS 서버는 루트 서버, TLD 서버 등을 거쳐 최종적으로 권한 있는 네임 서버에서 IP 주소를 받아옵니다.
    - 사용자의 컴퓨터는 이 IP 주소를 이용해 해당 웹사이트 서버에 접속합니다.
    - 이 과정은 DNS 정보가 캐시(임시 저장)되어 있으면 더 빠르게 진행될 수 있습니다. 

<br/>

### 1-1. DNS 구조 (계층 구조)

 - `루트 DNS 서버`
    - DNS 계층의 최상위
    - 모든 최상위 도메인(TLD)의 정보를 관리
    - 예: .com, .net, .kr
 - `TLD DNS 서버`
    - .com DNS 서버는 com 도메인 목록을,
    - .kr DNS 서버는 kr 도메인 목록을 관리
    - 예: naver.com을 찾으려고 하면 .com DNS가 연결된 네임서버 위치를 알려줌.
 - `Authoritative DNS 서버(권한 있는 DNS 서버)`
    - 도메인의 최종 IP 주소 정보가 저장된 DNS 서버
    - 예: 가비아에서 도메인을 샀다면 가비아 네임서버가 여기 역할

<br/>

### 1-2. DNS 조회 과정

 - 브라우저 캐시 확인
 - 운영체제(OS) DNS 캐시 확인
 - 로컬 DNS 서버(인터넷 제공업체 ISP)에게 질의
 - 로컬 DNS 서버는 아래와 같이 조회함
    - 루트 DNS 서버
    - TLD 서버 (.com)
    - Authoritative DNS 서버(해당 도메인 네임서버)
    - IP 주소를 최종적으로 얻음
 - 로컬 DNS 서버가 브라우저에게 IP 주소 반환
 - 브라우저는 해당 IP 서버와 연결

### 1-3. DNS 레코드

DNS레코드(또는 영역 파일)는 권한 있는 DNS 서버에 있는 명령으로서, 도메인에 연계된 IP 주소 및 해당 도메인에 대한 요청의 처리 방법에 대한 정보를 제공한다. 이 레코드는 DNS 구문이라고 하는 일련의 텍스트 파일로 구성된다. DNS 구문은 DNS 서버에게 수행할 작업을 알려주는 명령으로 사용되는 문자열이다.

 - A: 도메인을 IPv4 주소로 매핑
 - AAAA: 도메인을 IPv6 주소로 매핑
 - CNAME: 별칭 도메인 → 실제 도메인
 - MX: 메일 서버 주소
 - TXT: 인증/검증 정보 저장 (SPF, DKIM, 구글 사이트 인증 등)
 - NS: 이 도메인을 관리하는 네임서버
 - SOA: 도메인의 기본 정보(관리자, 갱신 룰 등)
 - `레코드 예시`
    - A 레코드
        - google.com -> 142.250.198.110
        - google.com 요청시 '142.250.198.110' IP로 연결
    - CNAME 레코드 (도메인 별칭)
        - www.google.com -> google.com
        - www.google.com 요청시 google.com 도메인으로 연결
    - MX 레코드
        - MX → ALT1.aspmx.l.google.com
        - 구글 워크스페이스나 네이버웍스 같은 기업 이메일 설정할 때 사용
    - NS 레코드
        - ns1.gabia.co.kr
        - ns.gabia.com
        - 해당 도메인의 DNS를 관리하는 서버(네임 서버)
